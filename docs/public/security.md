# 安全与隐私

- 请勿在 Issue、截图或诊断文件中提供供应商密钥、公司访问凭证、环境文件或数据库。
- 服务端主密钥与数据库配套保管；签名更新私钥仅存在构建端，不能上传到公司服务器。
- 成员统计由服务端限制为当前账号；客户端传入其他成员编号不会扩大权限。
- 接入配置只更新托管字段；显式启用前备份当前文件。软件升级不应修改工具默认模型。
- 当前目标是单个公司内网部署，不是向互联网开放的多租户计费服务。
- 发现安全问题时请勿公开漏洞细节。仓库维护者启用 GitHub 私密漏洞报告后，通过 Security 页面提交；在此之前先请求私密联系渠道，不在公开 Issue 附上敏感数据。

开源前检查整个 Git 历史，而不仅是工作区。若曾提交真实凭证，先撤销或轮换，再处理历史。删除文件不能撤销已经泄露的凭证。
