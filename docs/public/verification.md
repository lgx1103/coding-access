## 后续版本回归参考

每个发布版本必须记录已通过与未通过的项目，不能用交叉编译代替 Windows 实机验收。

- 服务端：首次部署、旧数据库迁移、成员权限、日期边界、重试计数、未知用量、导出一致、备份恢复。
- 资源：长流式请求、多并发、结束与取消释放、冷却恢复、后台暂停轮询。
- 客户端：首次安装、旧版升级、登录保留、设置保存、工具路径、临时会话隔离。
- 更新：正常签名、损坏内容、错误签名、取消、重试、旧服务端、错误平台、安装权限与配置保留。
- macOS：Apple Silicon 本地验证；Intel 需要对应设备或专门测试记录。
- Windows：原生安装、CLI 检测、Store 应用、终端启动、更新器及卸载重装，均需 Windows 实机记录。
- 开源：许可证、依赖许可、敏感文件与历史扫描、README 可执行性、CI、版本说明。

本次自动化证据保存在开发工作区 output/verification；只将脱敏且适合公开的测试摘要放到 Release 中。
